# Cyber Resilience Act pre-launch checklist

Before commercial distribution in the EU:

- determine manufacturer/open-source-steward status;
- document intended purpose and foreseeable use;
- cybersecurity risk assessment;
- vulnerability handling policy;
- support/update period;
- technical documentation;
- SBOM/process;
- vulnerability reporting process;
- incident reporting process;
- conformity/CE obligations assessment for the final product category;
- user security information;
- contact for authorities;
- release/update security.

Do not rely on the fact that source code is public as an exemption. The commercialization model
matters.
