# Go-to-market

## Position
Avoid “another Gmail extension”.

Suggested category:
**Open-source local-first email security + inbox operations.**

Short promise:
“Your inbox, locally inspected, cleaned and reconstructed before you trust it.”

## Distribution ladder
1. GitHub source.
2. SiteWarden product page.
3. MSD Systems Lab page.
4. Signed GitHub releases.
5. Chrome Web Store companion.
6. Firefox AMO companion.
7. Edge Add-ons companion.
8. winget / Microsoft Store.
9. Homebrew Cask + notarized macOS package.
10. Flatpak/Flathub / AppImage.

## Credibility assets
- public threat model;
- security invariants;
- SBOM;
- vulnerability disclosure policy;
- changelog;
- signed releases;
- independent audit report when funded;
- public roadmap;
- transparent permissions page.

## Launch content
- “Why email security cannot stop at spam filtering”
- “Why SiteWarden Mail never renders original email HTML”
- “What our app can and cannot protect you from”
- “Every permission we request, explained”
- comparison pages against productivity-only and cleanup-only competitors.

## Avoid
- “unhackable”;
- “100% secure”;
- fake antivirus claims;
- fear-based marketing;
- vanity download counts.
