# Funding opportunities — checked 2026-10-04

## 1. NGI Open Internet Stack Restack — highest immediate fit
Current call: 3 September–3 November 2026, 12:00 CET. The programme states grants of €5,000–€50,000 and explicitly accepts SMEs, individuals, academics, public sector and non-profits. Outcomes must be open.

Source: https://ngi.eu/opencalls/

## 2. Prototype Fund Germany — potentially strong fit, but applicant eligibility matters
The current Jahrgang 03 deadline is 30 November 2026. Innovation/Resilienz topics fit open-source security/software infrastructure. However, the Prototype Fund application guide states that companies/organizations are not eligible; it supports individual developers or small teams (up to four people). Do not submit MSD as a company without first confirming an eligible applicant structure.

Sources:
- https://bewerben.prototypefund.de/
- https://www.prototypefund.de/uploads/Publikationen_und_Onepager/ApplicationGuide.pdf

## 3. GitHub Secure Open Source Fund — after public traction
GitHub currently lists $10,000 per selected project, rolling applications and a security education/support programme. The project needs a clear governance/security story and benefits from existing public usage/traction.

Source: https://github.com/open-source/github-secure-open-source-fund

## Sequence
1. Public repo + product/security landing page.
2. NGI application before 3 Nov 2026.
3. Assess Prototype Fund applicant eligibility; apply before 30 Nov 2026 if eligible.
4. Sponsors/design partners.
5. GitHub Secure Open Source Fund once public traction exists.
