# Delete safety

“Unnötige E-Mails löschen” is useful but dangerous.

Design:
1. classifier suggests a group;
2. show count, senders, age range, categories and representative samples;
3. default action = archive;
4. second option = trash;
5. permanent delete only through a separate manual path;
6. keep an action ledger;
7. offer undo while provider trash retention allows it;
8. rules cannot call permanent delete.

This is deliberately more conservative than an ordinary cleanup utility because the product also
markets itself as a security tool.
