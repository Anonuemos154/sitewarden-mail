# Release gates

## Private alpha
- test accounts only;
- clear pre-release warning;
- no permanent delete;
- no auto-update.

## Public beta
Required:
- OAuth verification path understood;
- signed Windows/macOS packages;
- privacy policy;
- vulnerability reporting;
- threat model;
- lockfiles;
- dependency/vulnerability scan;
- rollback/update plan.

## Stable
Additionally:
- independent security review;
- documented support period;
- SBOM;
- signed provenance;
- incident runbook;
- CRA assessment;
- provider-policy compliance;
- data protection/legal review.
