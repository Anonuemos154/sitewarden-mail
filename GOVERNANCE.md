# Governance foundation

Before the repository accepts external code, define:

- project owner / trademark owner;
- maintainer roles;
- security release authority;
- who controls signing keys;
- review requirements;
- contributor licensing policy;
- conflict-of-interest policy for paid sponsors;
- rule for security embargoes;
- process for removing compromised maintainers/keys.

No sponsor should receive access to mailbox content or the ability to silently weaken security
rules in exchange for funding.
