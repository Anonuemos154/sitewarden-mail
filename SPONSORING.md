# Sponsoring SiteWarden Mail

SiteWarden Mail is intended to keep its core security and local-first mail functionality open
source. Sponsorship helps pay for work that is difficult to fund through ordinary feature sales:
security review, fuzzing, provider verification, code signing, reproducible releases, vulnerability
response and independent audits.

## Recommended GitHub Sponsors tiers

### Monthly
- **$5 — Supporter**: support ongoing maintenance.
- **$25 — Builder**: support development and testing.
- **$100 — Project Sponsor**: name/company listed in sponsor acknowledgements if desired.
- **$500 — Founding Sponsor**: sponsor acknowledgement plus periodic roadmap briefings.
- **$2,500 — Strategic Sponsor**: contact us first; usually handled as a written company agreement.

### One-time
- **$25 — Thank you**
- **$100 — Build contribution**
- **$500 — Release sponsor**
- **$2,500 — Security milestone sponsor**
- **$10,000 — Audit / major milestone sponsor**: contact us before sponsoring at this level.

Sponsorship does **not** purchase a guarantee that a requested feature will ship, does not bypass
security review, and does not convert Alpha software into a production SLA.

For commercial pilots, deployment, OEM use or a contractual support relationship, see
[COMMERCIAL.md](COMMERCIAL.md).
