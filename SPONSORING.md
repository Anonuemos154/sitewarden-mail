# Sponsoring SiteWarden Mail

SiteWarden Mail is intended to keep its core security and local-first mail functionality open
source. Sponsorship helps finance security review, fuzzing, provider verification, code signing,
reproducible releases, vulnerability response and independent audits.

Sponsorship tiers are configured through the active sponsor platform rather than hard-coded into
the repository. This keeps public pricing flexible and lets organizations discuss strategic support
directly.

Sponsorship does not purchase a guarantee that a requested feature will ship, does not bypass
security review, and does not convert Alpha software into a production SLA.

For commercial pilots, deployment, OEM use or contractual support, see
[COMMERCIAL.md](COMMERCIAL.md).
